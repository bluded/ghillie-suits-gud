## Used but not included

The mod loads these from your existing install at runtime. It doesn't copy or redistribute them.

### Game and engine

- **S.T.A.L.K.E.R.: Anomaly** - Anomaly Team, based on S.T.A.L.K.E.R. by GSC Game World. Ghillie suit outfit, models and base configs.
- **Modded exes (X-Ray Monolith)** - themrdemonized (https://github.com/themrdemonized/xray-monolith). DLTX config patching and the engine's Lua API.

### G.A.M.M.A.

- **G.A.M.M.A.** - Grokitach and the G.A.M.M.A. team. Outfit balance and the trader buy lists the wrap is added to.
- **Perk-Based Artefacts** - Demonized. Belt attachment template (`af_base`) the wrap is built on.
- **THAP Rework** - IENCE. First-person ghillie arms (`actor_hud_ghillie`) in stock G.A.M.M.A. Other hands packs (e.g. M.H.P. Hands Pack - Max_im16, Anomaly Hands Modernization Project - Kmack & Maka) replace them, and the wrap uses whichever is installed.
- **Mod Configuration Menu (MCM)** - RavenAscendant. Settings page.

### Detection scripts the mod hooks into (whichever is installed)

- **Atmospherics** - Hippobot
- **Stealth Overhaul** - xcvb
- **G.A.M.M.A. Stealth Crash Fix** - G.A.M.M.A. team
- **REDONE Combat AI Foliage Detection** - eAkman

### Optional compatibility

- **Wearable Devices** - Sulik, Jeremussy and Wiarubane (https://github.com/sulikz/st-wearable-devices). Its bracer state is read so the left arm can avoid clipping.
- **Sloptimizer 9000 for Stalker GAMMA** - businessdrewski-hash (https://github.com/businessdrewski-hash/sloptimizer-9000-for-Stalker-GAMMA). Performance patches this mod waits for before installing its hook.
